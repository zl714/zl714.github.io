Enhancement Two

Algorithms and data structures

Reusable criteria, consistent age calculations, record validation, scoring, and sorting transform rescue requirements into an understandable decision process.

DictionariesValidationUnit conversionScoringSorting

Artifact description

The artifact I selected is the Grazioso Salvare Rescue Dog Dashboard that I originally created for CS 340. The dashboard connects to an animal shelter database and helps users find dogs that may be suitable for water rescue, mountain or wilderness rescue, and disaster or individual tracking. It displays the animals in a table and includes a breed chart and location map.

Justification for inclusion

I selected this artifact because it gave me an opportunity to improve how the program filters, evaluates, and organizes animal records. I created a Python dictionary that stores the breed and age requirements for each rescue category. This keeps the requirements together instead of repeating similar filtering conditions throughout the dashboard.

I also added functions that validate animal records and apply the selected breed, age, and location filters. The age controls now begin at zero because negative ages in the source data are not valid. Users can select weeks, months, or years, while the program converts the selection back into weeks to match the database.

Another major improvement was adding a rescue suitability score. Dogs receive points based on their breed, age, and whether they have valid location information. The dashboard can rank the strongest candidates first or sort the results by breed, age, or name. These improvements demonstrate my ability to use dictionaries, functions, filtering, validation, calculations, and sorting algorithms.

The filtering process converts different user-facing age units into one database value, then applies the rescue criteria consistently before ranking or sorting the results.

Course outcomes

The main course outcome addressed by this enhancement was designing and evaluating computing solutions using algorithmic principles and computer science practices. The rescue criteria, candidate validation, scoring system, and sorting options demonstrate progress toward this outcome. The enhancement also supports the outcome involving the use of appropriate tools and techniques to create solutions that provide value. I met the outcome goals I planned for this enhancement and do not need to make major changes to my original outcome coverage plan.

Reflection

The most important thing I learned was that an algorithm should be understandable as well as functional. The original filters worked, but the logic was difficult to reuse. Separating the filtering, validation, scoring, and sorting tasks made the program easier to understand and maintain.

One challenge was improving the algorithms without changing the dashboard’s original purpose or breaking its existing features. Another challenge was handling incorrect or missing data, including negative ages and invalid location information. I added validation so those records would not cause incorrect filtering or mapping results.

I tested the enhancement with the local database of 78,256 animal records. The original rescue filters continued returning the expected results, and I also tested the new age controls, unit conversions, suitability scores, sorting options, chart, and map. The enhancement made the dashboard more useful while demonstrating my growth in algorithms and data structures.
